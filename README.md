📌 About

This project uses the NEAT algorithm to train an AI agent to play Flappy Bird automatically. The AI evolves neural networks over generations to improve its gameplay.

🧠 How It Works

<p align="center">
  <img src="assets/neat-workflow.png" alt="NEAT AI Workflow" width="100%">
</p>- Observe: Detect the bird's position and nearby pipes.
- Decide: The neural network decides when to flap.
- Evaluate: Fitness scores measure performance.
- Evolve: Selection and mutation help improve future generations.
